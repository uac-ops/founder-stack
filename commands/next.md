The founder is asking: "what should I do right now?"

1. Read `COMPANY.md` from the project root.
   - If missing, tell them to run `/new-company` first.
2. Look at `## Meta → Stage`, the `## Next Actions` list, and the current
   stage's section to judge what's actually unfinished.
3. Reply with ONE clear next action — the single highest-leverage thing to do
   now — and the exact skill or command to run for it.
4. If `finance` or `legal` is overdue (e.g. about to `launch` without `legal`
   done, or it's been a month without a `finance` check), say so.

Keep it to a few sentences. One recommendation, not a menu. Be decisive.
