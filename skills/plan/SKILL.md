# Plan — scope the smallest winning thing

A solo founder's scarcest resource is time. Planning is the art of cutting until
only the spine of value remains, then committing to build that.

## Connected skills
- Reads:    `## 01 Idea`, `## 02 Validation`
- Writes:   `## 03 Plan`
- Agents:   `product-strategist`, `architect`
- Previous: `validate`
- Next:     `design`

## Goal
A crisp MVP definition, an in/out scope line, a chosen stack, and milestones you
can ship solo.

## Inputs
- Validated problem and demand evidence from `## 02 Validation`.

## Process
1. **Define the core job.** The one thing the product must do for a user to get
   value. Everything else is negotiable.
2. **Cut to the MVP.** With `product-strategist`, list features and ruthlessly
   sort into:
   - **MVP** — required to deliver the core job once.
   - **Fast-follow** — valuable but not for launch.
   - **Never** — kill it now to protect your focus.
3. **Draw the scope line.** Write what is explicitly OUT. This is more important
   than what's in.
4. **Pick the stack.** With `architect`, choose boring, fast-to-ship technology
   you know. Optimize for time-to-first-user, not resume value. Note hosting,
   data store, auth, payments.
5. **Sequence milestones.** Break the MVP into 1–2 week chunks, each ending in
   something demoable. Define "done" for the MVP.
6. **Estimate honestly,** then add buffer. Solo timelines slip.

## Exit criteria
- One-sentence MVP definition.
- Explicit in/out scope.
- Chosen stack with rationale.
- Milestones with a "done" line.

## Update the ledger
- Fill `## 03 Plan`.
- Decision Log: `YYYY-MM-DD · MVP scoped · stack = <X> · out of scope = <Y>`.
- Set `Stage: design`.
- Next Actions: "Run `design` to make the MVP desirable."

## Handoff
"Scope is locked. Next run `design` — brand, design system, and the key flows
for the MVP we just scoped."
