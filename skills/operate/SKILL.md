# Operate — run the machine

You're live. Operating is the steady state of a one-person company: measure what
matters, automate what repeats, and loop through the growth cycle without
burning out.

## Connected skills
- Reads:    everything (the whole ledger)
- Writes:   `## 16 Operations`
- Agents:   `finance-clerk`, `growth-marketer`
- Previous: `support`
- Next:     loops — `support → market → sell → finance → operate`

## Goal
A measured, partly automated business you can run sustainably solo, with a clear
signal for what to improve next.

## Inputs
- The full ledger; especially Sales, Marketing, Support, Finance.

## Process
1. **Pick ONE north-star metric.** The single number that best captures
   delivered value (e.g. weekly active users, paying customers, jobs completed).
   Everything else is a supporting metric.
2. **Build a simple dashboard.** North star + the funnel (visitors → signups →
   paid → retained) + finance (MRR, runway) on one screen. Check it weekly.
3. **Automate the repetitive.** With the agents, set up:
   - Recurring digests (metrics, errors, new signups).
   - Onboarding/lifecycle emails.
   - Alerts (downtime, payment failures, error spikes).
   - Scheduled content/social if that's your channel.
4. **Run the weekly loop:**
   - **support** — what hurt this week? (feeds the roadmap)
   - **market** — keep the channel fed.
   - **sell** — improve one funnel step.
   - **finance** — update the numbers.
   - **operate** — pick the single highest-leverage improvement; ship it.
5. **Keep the discovery + data loop running.** Use `research` for continuous
   customer discovery and `experiment` to turn analytics into tested
   improvements. These feed the roadmap with evidence instead of guesses. Run a
   `polish` pass on rough surfaces as you go.
6. **New features re-enter the build loop:** `plan → design → prototype → build →
   code-review → test → deploy`, with `accessibility` and `performance` passes
   before they reach users. Don't skip validation for big bets.
7. **Protect the founder.** Set boundaries and routines so the machine doesn't
   consume you. A burned-out founder is the top operational risk.

## Exit criteria
- A north-star metric chosen and tracked.
- A one-screen dashboard.
- At least the core routines automated.
- A weekly operating cadence in place.

## Update the ledger

- Decision Log: `YYYY-MM-DD · operating · north star = <metric>`.
- Keep `Stage: operate` (steady state).
- Next Actions: the next single improvement from the weekly loop.
