# Examples

A worked example is the fastest way to understand Founder Stack.

## [`COMPANY.md`](COMPANY.md) — a fully filled-in ledger

This is what your `COMPANY.md` looks like after a fictional company,
**ShipDigest**, has moved through the entire lifecycle to `operate`. It shows:

- How every stage's section gets filled in over time.
- How later stages reuse earlier context (sales pricing traces back to the
  validation pricing signal; the north-star metric reflects the actual value).
- How the **Decision Log** becomes the company's memory, with dates.
- How the cross-cutting `finance` and `legal` stages slot in (after validate,
  before launch) rather than at a fixed step.

Your own ledger starts nearly empty — see [`../templates/COMPANY.md`](../templates/COMPANY.md)
— and fills in as you run each stage. Run `/new-company` to create yours.

Nothing in the example is real. It exists only to teach the system.
